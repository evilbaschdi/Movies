# Movies

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg?style=for-the-badge)](LICENSE)

Private project to manage my DVD and Blu-ray library.

## Features:

- Maintain "lend" information
- "Last watched" date
- Group by column
